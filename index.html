FAQ?

Do players need an account?

No. Only organizers and referees log in. Players check themselves in by scanning a QR code, and everything they need to follow — pool play, standings, the bracket — lives on public pages that need no sign-in.

What tournament format does it run?

Round-robin pool play (4–6 teams per pool) feeding a single-elimination bracket — Round of 8, 16, 32 or 64 — with the top two from each pool seeded in. A Bronze match for third place is generated automatically, and later bracket rounds can optionally be best-of-2.

Can I run several divisions at the same event?

Yes. Each division is a category with its own pool size, bracket size, timers and teams, so a Novice Round of 8 and an Open Round of 32 can run side by side under one tournament.

How do referees score matches?

From a phone. The referee opens the match, taps a player's name to set the server, and taps to record points. The card tracks server number and right/left court side using the real USA Pickleball doubles rules, with a confirm step on every side-out.

Does it need an internet connection?

No. Speedup is a self-hosted web app. On event day you run it from a laptop and everyone connects over the venue's local network — phones, tablets and the front-desk screen all hit the same address.

What if a score is entered wrong?

A referee's live score can be updated freely until it's saved as final. Once final, the winner is pushed into the next bracket round and only an organizer can make a correction — which keeps later rounds from silently showing the wrong team.
